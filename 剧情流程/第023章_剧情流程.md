# 第23章：五万块先拿走

壮汉因林骁拒绝彪哥而拍桌辱骂——林骁毫不退让，彪哥开口压住手下——周凯提起林骁十九岁时在酒吧一人打倒三人的往事——林骁反问当初为什么只有自己被拘留，揭开他与周凯之间的旧账——彪哥提出让林骁替自己照看两家酒吧和一家棋牌室，每月给两万元，同时允许他继续在云汀工作——林骁继续追问具体工作，发现所谓看场子还包括堵人、收账和强行带人——他当场拒绝——彪哥加码，承诺替林家平掉三十二万元债务——苏媛借着倒酒贴近林骁，劝他接受——林骁仍不愿重新走回过去的路——彪哥拿出五万元现金，让他先解决家里的燃眉之急，做满半年便不用偿还——林骁短暂动摇，最终把现金推回去——他怀疑催债人上门与彪哥有关，并警告他们不要再骚扰自己的父母——周凯接到电话后，彪哥带人先行离开——苏媛临走前对林骁产生更深兴趣——两名壮汉留下堵住包间，准备试探林骁的身手——其中一人挥拳砸来，林骁抬手接住他的拳头。

## 本章核心变化

林骁拒绝能够立刻解决债务的五万元，也与彪哥彻底谈崩；过去的社会关系、家庭债务和眼前的武力冲突正式连在一起。

## 情绪曲线

言语压迫 → 旧事揭开 → 高薪诱惑 → 工作越界 → 三十二万重诱 → 五万元近在眼前 → 推钱拒绝 → 正面警告 → 暗中翻脸 → 拳头袭来。
