# 第28章：五千块一次，来不来

周倩离开云汀后，林骁继续完成当天的工作——晚上回到人才公寓，他从工作服口袋里取出周倩的名片——想到周倩试按时不断后靠、握住自己手腕的动作，以及金链男人此前说过的那些话，林骁隐约觉得她的邀请不只是普通会员对调理师的欣赏。

林骁按照名片上的号码打过去——周倩接通电话后先拿他这么晚才联系自己开玩笑——随后告诉林骁，她想让他到家里做私人调理，不需要经过云汀，一次给五千元，时间和项目都可以由两人商量。

周倩说话始终带着暧昧，甚至故意问林骁会不会做全身放松——林骁虽然听出她在逗自己，却真的以为主要内容仍是正常推拿——他认真询问调理时长和身体情况，反而让周倩对他的反应更加感兴趣。

林骁想到家里月底前急需五万元——一次五千，连续做十次便能填上缺口，这笔收入对现在的他有很强的吸引力——但他刚进入云汀，不清楚会所是否提供上门服务，也不知道具体应该怎样安排——他没有立即答应，只告诉周倩，自己需要先向经理询问一下。

周倩没有逼他当晚过去，也没有要求他马上给出答案——她表示自己并不急这一晚，让林骁什么时候问清楚、什么时候再联系她——通话结束后，林骁没有扔掉名片，而是将它收进抽屉，周倩的私人邀约暂时保留下来。

## 情绪曲线

回家取出名片 → 主动拨通电话 → 周倩暧昧报价 → 误以为普通调理 → 五千元带来诱惑 → 谨慎提出询问经理 → 周倩不紧逼 → 邀约成为长线伏笔。
