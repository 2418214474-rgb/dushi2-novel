# 第26章：会所里的私人邀约

韩静换回工装，继续带林骁熟悉高级会员区——她告诉林骁，高级会员不仅在意手法，也重视服务人员能否记住自己的习惯和隐私——当天云汀正好举行每月一次的会员茶歇，几名做完项目的长期女会员聚在休息区喝茶聊天——理疗部安排调理师轮流提供简单的肩颈体验，顺便维护客户关系。

林骁跟着韩静进入休息区——几名衣着精致、保养良好的女会员很快注意到他——得知他是新来的高级调理师，女人们开始围绕他的年龄、长相和技术开玩笑——林骁只按照韩静教的方式回答。

其中一名女人主动开口——她三十五岁，经营一家服装店，烫着微卷长发，身材丰腴，穿着修身半裙——她听说林骁入职当天便被评为高级，要求他现场替自己试按几分钟——韩静确认符合茶歇体验流程，便把位置让给林骁。

女人坐在沙发上，让林骁替她放松肩颈——林骁站在她身后落手——她不断通过身体后靠、握住他的手腕和暧昧问话试探林骁——她询问林骁是否只在云汀工作、晚上有没有时间、能不能提供上门服务——林骁始终克制回答，没有越界。

几分钟体验结束——女人认可他的手劲和技术，却没有立刻在会所预约——离开休息区前，她将写有私人号码的名片塞进林骁的胸前口袋——她贴近林骁耳边，告诉他晚上可以去自己家单独服务，价格由他开。

韩静远远看到两人的动作，却没有听清女人说了什么。

## 情绪曲线

韩静关系缓和 → 高级会员集中登场 → 男主受到关注 → 熟女主动试按 → 身体与言语不断试探 → 私人邀约出现 → 金钱诱惑封章。
