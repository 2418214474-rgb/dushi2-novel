# 第27章：五千块一次，来不来

周倩离开后，林骁取出她塞进胸前口袋的名片——看到“周倩”两个字，他立即想起此前闯入云汀的金链男人——对方当时不仅询问周倩所在的房间，后来还带人堵在停车区，声称周倩在云汀充值了二十多万元，自己为了讨好她吃过不少蓝色药丸、尝试过各种高难度花样，最后却被她直接甩掉——林骁这才确认，刚才主动试探自己的熟女会员正是那个一直没有露面的周倩。

名片背面留着私人号码和一句让林骁晚上联系她的话——林骁想到家里月底前急需五万元，犹豫之后打电话询问具体服务内容——周倩表示只是让他上门替自己做私人调理，一次给五千元，现金或者转账都可以——她说话虽然暧昧，林骁却真的以为只是普通的上门推拿，只觉得她不愿通过会所预约，是为了节省流程并保证隐私。

五千元相当于他此前做许多单代驾的收入，连续接十次便能凑齐家里急需的钱——林骁确实产生动摇——他进一步询问能否通过云汀正常预约——周倩明确表示不经过会所，只想私下找他，而且价格还可以继续商量。

林骁意识到这已经属于私自承接会所会员——一旦被发现，不仅可能失去刚得到的高级调理师工作，也辜负了顾明月和宋妍替他争取的机会——他最终拒绝五千元的私人邀约，只告诉周倩，如果确实需要调理，可以通过云汀正式点名预约自己。

周倩没有生气，反而因为林骁在急需钱的情况下仍然拒绝她，对他产生更浓的兴趣——她让林骁保留名片，随后结束通话。

## 情绪曲线

名片揭晓身份 → 回忆金链男人闹事 → 私人邀约得到确认 → 误认为普通服务 → 五千元带来强烈诱惑 → 意识到飞单风险 → 克制拒绝 → 周倩兴趣加深。
