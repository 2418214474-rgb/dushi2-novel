# 第25章：内部实操

顾明月宣布，为了下周的团体接待，理疗部需要进行内部实操训练——高级理疗师当天都有预约，林骁虽然等级高，却不熟悉云汀的完整服务流程，因此被安排与中级理疗师韩静搭档——韩静二十七岁，在云汀工作三年，经验丰富，却一直没能升上高级——她表面上按照安排带林骁熟悉流程，实际上也想看看这个刚来几天便被评为高级的男人究竟有什么本事。

韩静先替林骁演示标准接待流程——林骁脱掉上衣趴上理疗床——韩静看到他宽厚结实的肩背，动作出现短暂停顿——她一边讲解精油、毛巾和询问步骤，一边替他试按——林骁从她落手的角度和发力变化中，察觉她的右手腕存在问题。

两人交换位置——韩静换上会所的理疗抹胸，露出肩背和腰身——林骁按照训练流程替她检查——宽大粗糙的手掌贴上皮肤，韩静原本只想判断他的手法，身体却逐渐放松下来——林骁发现她长期依靠手腕硬撑力量，导致腕部、肩胛和颈侧形成连带劳损，这也是她手法不够稳定、始终升不上高级的原因之一。

林骁替她进行针对性调理，并教她改变发力方式——韩静活动手腕和肩膀，发现困扰自己许久的酸痛明显减轻——她收起最初的怀疑，承认林骁的高级评级并非特殊照顾——训练结束后，韩静主动把自己积累的客户习惯和服务流程告诉林骁，双方建立初步信任。

## 情绪曲线

等级落差带来的好奇 → 男主脱衣、彼此观察 → 韩静换衣，暧昧升温 → 手法试探 → 找出职业劳损 → 症状缓解 → 真正认可。
