# 第24章：工作标题待定

壮汉的拳头被林骁单手接住——对方想要抽回手臂，却发现林骁的力量远超预料——另一名壮汉从侧面扑来，林骁借势将面前之人撞过去——两人配合被打乱，林骁凭借过去积累的实战经验逐个击破——彪哥等人在走廊等待，本以为很快便能听见林骁求饶——包间里连续传出几声闷响，随后彻底安静——房门打开，两名壮汉已经倒在地上，林骁却只是衣服稍显凌乱——周凯震惊，苏媛望向林骁的目光明显变得火热——林骁当面警告彪哥，不管催债人与他有没有关系，都不许再去骚扰自己的父母——彪哥没有立即翻脸，反而确认林骁比以前更加能打，对他的招揽也更加强烈——林骁直接离开酒吧。

林骁回到人才公寓休息——第二天照常前往云汀上班——会所正在为江曼丽带来的团体体验做准备——顾明月临时召集全体员工开会——刘思雅仍在请假，没有参加会议——顾明月以贴身上衣和高腰包臀裙亮相，雪白肌肤、成熟身材和眼角泪痣形成鲜明特点——林骁第一次见到会所大部分员工，发现除了少数男员工，现场几乎全是年轻漂亮的女人——陈璐身材丰润、气质温和，另一名资历较深的女调理师高挑成熟，其余女员工也各有特点——女员工同样注意到新来的高级调理师林骁——马志鹏发现女同事频频关注林骁，心里更加不舒服。

顾明月说明江曼丽会带来一批网红和商务客户——此次体验包括皮肤管理、身体状态恢复和养护产品搭配——各部门需要提前熟悉衔接流程——具体服务人员暂时不固定，将根据技术特长和客户需求临时分配。

## 本章爆点

彪哥本想试探林骁，结果两名壮汉在短时间内全部被放倒。

## 情绪曲线

拳头被接 → 以一敌二 → 两名壮汉倒地 → 当面警告彪哥 → 苏媛兴趣加深 → 次日回归会所 → 美女员工集中登场 → 团体项目压力出现。
